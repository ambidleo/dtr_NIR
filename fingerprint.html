Laptop Fingerprint Enrollment

This page registers each employee’s fingerprint sensor on this laptop using the browser’s WebAuthn API. When an employee touches the sensor, Windows Hello (or Touch ID) verifies the fingerprint and returns a credential. That credential is saved locally and used by the Time Kiosk to confirm identity.

Important: Enrollment and verification must happen on the same laptop. Fingerprints cannot be exported or copied to another device.

How WebAuthn Fingerprint Works

What the browser provides

A cryptographic credential ID tied to this laptop’s platform authenticator. The actual fingerprint image never leaves the sensor, and JavaScript cannot read or store it.

What this means for the kiosk

If the enrolled finger touches the sensor, the credential is returned and the employee is accepted. If a different finger touches it, the browser rejects the request — there is no “similarity match” and no chance of accepting the wrong person.

Requirement: HTTPS or localhost

WebAuthn only runs on a secure origin. file:// will not work. Serve the pages from localhost, GitHub Pages, or any HTTPS host.

Browser support

Chrome, Edge, Safari, and Firefox on Windows 10/11, macOS, and most modern Linux desktops support platform authenticators. If the laptop has no fingerprint sensor, the browser will fall back to PIN or Windows Hello face if those are configured.
